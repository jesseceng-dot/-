# 已交付各书复查报告（第 29 册之后）

范围：仓库里所有已交付的 PDF——黑格尔 4 卷与合集、康德 10 册与合集、杜威 11 册与合集、16 开第 1–10 册和第 16–29 册，共 52 个分册 PDF 和 3 个合集。按用户要求，用户自传的《初中数学竞赛多功能题典_最终校勘版.pdf》没有检查。

## 1. 怎么查的

只看成品 PDF，不依赖当初的构建数据（`python -m tools.audit_pdf <pdf> -v`，下表各项都在里面，段内短行除外）；脚本报出的每一处都放大看过，分清真问题和误报。

| 检查 | 内容 |
|---|---|
| foot | 非章节末页的页底留白 |
| grid | 正文行不在行格上 |
| kinsoku | 行首是句读、右括号，行尾是左括号（只看版心左右边缘的行） |
| over | 文字越出版心右边（只算有墨迹的字，行末的全角空格不算） |
| overlap | 两行文字压在一起 |
| lone | 只有标点或只有注码的一行 |
| short | 只有一两行、又不是新章节开头的页 |
| head_bottom | 标题落在页底最后两行、下面没有正文 |
| links / joiner / empty / type3 | 坏链接、占宽度的词连接符、空白页、Type3 字体 |
| markstart | 上标注码排在一行的最左端 |
| numbreak | “图7-”“1797—”“pp.355—”“p.”在行末，后面的数字到了下一行 |
| 段内短行 | 段落中间的行没排到右边（行末留空；单独扫描，全部是误报：索引、对话行、链接列表） |

- 黑格尔第 2 卷、第 4 卷 6 处行首的“……”都是段落或引文开头的省略号，属于正常排法。
