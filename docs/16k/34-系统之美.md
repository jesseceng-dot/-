# 《系统之美》（全新升级版）：转换说明与验收

源文件：EPUB（〔美〕德内拉·梅多斯 著，邱昭良 译；浙江教育出版社 2023，湛庐；原书 Thinking in Systems: A Primer），`source/xitong-zhi-mei.epub`；成品：`out/16k/34-系统之美.pdf`（210 页，8.9 MB）。

## 1. 底本与改动

- 电子书有人修补过：书里的百分数、温度、区间、分数、正负分值，以及附录“系统模型公式”的全部模型式子，都是 LaTeX 小图（每张带 alt 文字），162 种 222 处；第 5 章“陷阱”“对策”小标题前的灰色图标（×、○）16 处。这里全部转成文字（见第 2 节）。修补者另加了 3 条“本次校订注”，照原样保留。
- **按要求没有通读校订。** 转换时改了 4 条，列在 [`errata/34-系统之美.md`](errata/34-系统之美.md)：中文里的半角括号改全角；译者导读里列举问题之后单独成段的“……”接在最后一问之后（单独一行是孤立的标点行）；“图2-18”的“图”与编号、“〔校订注1〕”的各字之间加不占宽度的连接符，不在行末拆开。
- 其余照原样。

## 2. 版式与结构

- 版式与本仓库其余 16 开书相同：页面 481.89 × 680.31 pt，正文思源宋体 10.5 pt，每页 32 行 × 34 字、行距 17 pt，整页末行基线 615.0 pt。
- 封面只有电子书里这一张（428 × 616 像素），照用。
- 顺序：
  - 封面 → 书名页 → 版权页（电子书的版权信息）→ 目录；
  - 测一测、作者简介（作者卡片图与三幅照片；“20世纪最有影响力的环境思想家之一”这类小标题排黑体）、重磅赞誉（推荐人姓名、头衔右对齐）、推荐序、译者导读、前言（罗马页码）；
  - 正文：引言，三个部分（各一页部分页）共 7 章；
  - 书末：附录“系统思考：理解、应用与对策”、译者后记、注释。
- **段落样式照电子书的区分**：举例、引文段排楷体（电子书的 quotation）；每段要点排黑体、不缩进，其后的标签“系统之思 / THINKING IN SYSTEMS”右对齐黑体（全书 60 处，电子书就是先要点、后标签）；章首题词楷体，出处右对齐。
- **注释**：电子书把全部注释放在书末一个文件里：
  - 原书注释 21 条（编者注、译者注；正文里的角标是一个小图标）：角标排成 [1]–[21]；
  - 本次校订注 3 条（修补者加的，正文里写作“〔校订注1〕”，小字上标）：照原样排；
  - 两组合成书末一节“注释”，与角标双向链接。
- **行内小图**（162 种，逐个对照图形核对）：
  - 正文：百分数、千分数、温度、区间（3～8）、分数（1/3）、“70/7=10”、正负分值（−10、+10），“世界模型Ⅲ”的 Ⅲ；
  - 附录的模型式子：每行一张图，同一行折成两张的合回一段；变量 *t*、*dt* 排斜体（与图里一致），减号统一用“−”（alt 里 - 与 – 混用），“(50 ℉)”写作“（50℉）”；括号、区间号照 alt。式子左对齐，折行时续行缩进两字。
- 图 61 幅，图题、图注在图下，留在原位。
- 目录列部分、章、节三级，页码可点击，空行固定。书内链接 204 个；书签 90 个。

## 4. 这次顺带加的功能（对以后各册同样有效，都要在 `CFG` / `bk_fixes` 里打开）

- 抽取：`<section epub:type="footnote">`（标题“注1”、正文、“返回正文”链接）排成一条注释；正文里的图标角标取链接目标的编号（N01 → 1）；`editorial-ref` 链接排成上标；类为 `formula-block` 的整段公式图当作一段文字。
- `note_group_h='all'`：书末注释部件里每个标题都开一组（这里是“原书注释”“本次校订注”）。注释标签“〔校订注1〕”这样比编号栏宽的，排在行内。
- `epi_name_air`：题词出处不带“——”时，也可以在出处之下多空一行（第 2 章首页因此不必撑开行距）。
- `fig_air`：指定的图可以多留 3 行空（作者简介避免一行段尾落到下页页首）。
- `head_cls` 用正则只把部分 `content-b` 段排成标题，标签行除外。
