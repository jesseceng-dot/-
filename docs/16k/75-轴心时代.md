## 2. 版式与结构

- 版式与本仓库其余 16 开书相同：页面 481.89 × 680.31 pt，正文思源宋体 10.5 pt，每页 32 行 × 34 字、行距 17 pt，整页末行基线 615.0 pt。
- 顺序：
  - 封面 → 理想国的两页（电子书封面之后的两张图）→ 书名页 → 版权页（CIP）→ 目录 → 推荐序 → 前言；
  - 第一—四部分（第 1—10 章）→ 术语 → 译后记 → 理想国二维码页 → 封底。
- 每章：部分页（“第一部分　酝酿”）、章名，章名下的年代（“（约公元前1600年—公元前900年）”）居中，四节（“一、雅利安文明”）和节下的小标题。电子书每节是一个文件，注释在每节之后、每节从 [1] 编起；这里每章的注释排在章后，按章连续编号（`renum`），注码与注文双向链接。注释 1350 条。
- **甲骨文释文里的四个字**，电子书是造字图片，照图转成字，正文字体没有这几个字，用思源宋体自己的笔画拼合（`fonts.compose_dao` 等），风格与正文一致：
  - “于父甲𠦪田”的 𠦪（U+209AA，⿱卉夲，祷）；
  - 婦好娩“𰋶”的 𰋶（U+302F6，⿰女力，嘉）；
  - “貞方𢦏征”的 𢦏（U+2298F，⿶戈十，災；思源宋体有此字）；
  - “隹帝令乍我𡆥”的 𡆥（U+211A5，⿴囗卜，祸）。
  - 码位按汉字构形数据（cjkvi-ids、CHISE IDS）定，四字都与上下文的释义相合（“好”“方国在损害和攻击我们”“给我们制造灾难”“祈求好收成”）。
- 插图 23 幅（地图、谱系图、祭坛图）留在原位；图下译者的图注（“① 今译为加沙。”“（本书所有地图均为英文版原书地图）”）排成小字，几条图注都左对齐（`cap_left`）。没有图造成页底留白，所以没有书后插图。
- 引文仿宋体（这里用楷体），推荐序、译后记的署名右对齐；术语表的字母分组标题（A、B……）加粗；《诗经·天作》引文里的着重号照排。
- 书内链接 6818 个，书签 71 个。

## 4. 这次加的功能

- `fonts.compose_dao`、`compose_jia`、`compose_huo`：用思源宋体的笔画拼合 𠦪 𰋶 𡆥（所有书的正文字体子集里都有这三个字形，不用的书不受影响）。
- `cap_left`：一幅图下有几条图注时都左对齐（默认仍是一行的居中、多行的两端对齐）。

BOOK_SCRATCH=<dir>/q75 BOOK_GEOM=k16 BOOK_FONT_DIR=<dir>/fonts python -m tools.bk_report 75
