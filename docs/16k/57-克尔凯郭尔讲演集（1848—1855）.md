## 2. 版式与结构

- 版式与本仓库其余 16 开书相同：页面 481.89 × 680.31 pt，正文思源宋体 10.5 pt，每页 32 行 × 34 字、行距 17 pt，整页末行基线 615.0 pt。
- 顺序（与电子书相同，版权页移到书名页之后）：封面 → 书名页 → 版权页 → 目录 → 《克尔凯郭尔文集》中文版序 → 天才释放出的尖利的闪电 → 译者短语 → 基督教的讲演 → “大祭司”——“税吏”——“女罪人” → 一个陶冶性的讲演 → 在星期五圣餐礼仪式上的两个讲演 → 上帝的不变性一个讲演。
- 五部著作（基督教的讲演，“大祭司”——“税吏”——“女罪人”，一个陶冶性的讲演，在星期五圣餐礼仪式上的两个讲演，上帝的不变性）各有篇页：书名和电子书里书名页的几行（作者、出版地、出版者、印刷者、年份、题献）。
- 《基督教的讲演》的四个部分有小一号的篇页，篇页之后是这一部分的目录（照电子书）和祈祷文、经文；每篇讲演一章，注释排在各篇之后（照电子书）。
- 注码 [n] 在电子书里是普通上标，没有链接；每篇末尾的“注释：”下每篇从 1 编起。这里按篇配对，双向链接。
- 电子书缺一条注文：《基督教的讲演》第一部分“II　丰裕之忧虑”的注 [6]（“第一桶金”），注 [5] 之后就是 [7]。角标照排，不加链接。
- 《上帝的不变性》只有一篇讲演，前言、祈祷和讲演排在篇页之后。
- 行内小图 8 处（8 种）转成文字。
- 目录页码可点击；书内链接 8566 个，外部链接 0 个，书签 94 个。
