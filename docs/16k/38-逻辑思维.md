源文件：AZW3《认知三部曲（全三册）》（〔美〕理查德·尼斯贝特 著；中信出版集团电子书）里的第三本，张媚 译（原书 Mindware: Tools for Smart Thinking），`source/renzhi-sanbuqu.azw3`；成品：`out/16k/38-逻辑思维.pdf`（242 页，2.7 MB），三册合集 `out/16k/36-38-认知三部曲（合集）.pdf`。三册共同的做法（封面、版权页、人名间隔号、注释、合集）见 [`36-思维版图.md`](36-思维版图.md)。

## 1. 底本与改动

- **按要求没有通读校订。** 没有发现需要改的明显错误，勘误表 [`errata/38-逻辑思维.md`](errata/38-逻辑思维.md) 是空的。
- 书末“总结 常人科学家的工具箱”在电子书里用半角空格隔开，照各章（“第1章　推理的世界”）的写法统一成全角空隙（目录、书签、页眉同样）。

## 2. 版式与结构

- 版式与本仓库其余 16 开书相同：页面 481.89 × 680.31 pt，正文思源宋体 10.5 pt，每页 32 行 × 34 字、行距 17 pt，整页末行基线 615.0 pt。
- 顺序（与电子书相同）：封面 → 书名页 → 版权页 → 目录 → 序言 → 六个部分（16 章）→ 总结 → 致谢 → 注释（4 条，排在全书最后）。
- 每个部分先是一页部分页（“第一部分”和部分名），随后是这一部分的导言（电子书里接在部分名之后、没有标题的几段），再是各章。导言不单独作书签和目录条目，页眉用部分名（`part_intro`）。
- 引文段排楷体，出处右对齐；18 幅图（实验图片、图表、维恩图等）留在原位，图注在图下。
- 书内链接 140 个，外部链接 2 个；书签 122 个（部分、章、节三级）。
