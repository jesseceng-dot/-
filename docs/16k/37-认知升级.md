# 《认知升级》（认知三部曲之二）：转换说明与验收

源文件：AZW3《认知三部曲（全三册）》（〔美〕理查德·尼斯贝特 著；中信出版集团电子书）里的第二本，仲田甜 译（原书 Intelligence and How to Get It），`source/renzhi-sanbuqu.azw3`；成品：`out/16k/37-认知升级.pdf`（186 页，2.5 MB），三册合集 `out/16k/36-38-认知三部曲（合集）.pdf`。三册共同的做法（封面、版权页、人名间隔号、注释、合集）见 [`36-思维版图.md`](36-思维版图.md)。

## 1. 底本与改动

- **按要求没有通读校订。** 没有发现需要改的明显错误，勘误表 [`errata/37-认知升级.md`](errata/37-认知升级.md) 是空的。
- 汉字后的 3 个半角问号改成全角（第 7 章两处、第 8 章标题“亚洲人智商更高还是更努力?”），这是各册通用的标点规范化，不列入勘误表。

## 2. 版式与结构

- 版式与本仓库其余 16 开书相同：页面 481.89 × 680.31 pt，正文思源宋体 10.5 pt，每页 32 行 × 34 字、行距 17 pt，整页末行基线 615.0 pt。
- 顺序（与电子书相同）：封面 → 书名页 → 版权页 → 目录 → 正文 10 章 → 结语 → 附录一、附录二 → 致谢 → 注释（28 条，按章分组）。
- 电子书每章开头有同一张装饰图（10 处），不排；章名下的题词照电子书排：引语楷体，署名加粗、右对齐。
- 引文段缩进；楷体段落照电子书；“表1–1”这样的表题排在表上，“资料来源”排在表下；图注在图下。图和表格图片共 11 幅，留在原位。
- 原来分在第 7 章之后和结语之后的两组注释，按三册统一的做法合成书末一处（全书最后）。
- 书内链接 227 个，外部链接 2 个；书签 90 个（章、节两级）。
