## 2. 版式与结构

- 版式与本仓库其余 16 开书相同：页面 481.89 × 680.31 pt，正文思源宋体 10.5 pt，每页 32 行 × 34 字、行距 17 pt，整页末行基线 615.0 pt。
- 顺序（与电子书相同，版权页移到书名页之后）：封面 → 书名页 → 版权页 → 目录 → 《克尔凯郭尔文集》中文版序 → 天才释放出的尖利的闪电——克尔凯郭尔简介 → 译者的话 → AA：12 吉勒莱日记 → 日记JJ → 日记 NB。
- 三部日记（AA：12 吉勒莱日记、日记 JJ、日记 NB）各成一章；条目编号、日期照排，条目之间的分隔行（“＊＊”“_______”“=”“#”）照电子书居中排。
- SKS 版的 ▶ ◀ 标记照排；单独成段的“◀”在电子书里就是单独一行，靠右。
- 正文里的注码“（n）”在电子书里是普通文字；按编号与注释配对，双向链接（注码偶尔前后颠倒的也认得）。作者原注 [n] 照电子书的链接，原注里的注码也链接到相应的注释。
- 日记里的小插图（墨迹、符号）留在原位。
- 目录页码可点击；书内链接 4255 个，外部链接 0 个，书签 13 个。
