- 版式与本仓库其余 16 开书相同：页面 481.89 × 680.31 pt，正文思源宋体 10.5 pt，每页 32 行 × 34 字、行距 17 pt，整页末行基线 615.0 pt。
- 顺序：封面 → 书名页 → 版权页 → 目录 → 序言 → 研讨会的参与者 → 各章总结 → 主编和撰稿人信息 → 致谢 → 缩写 → 第一—七章 → 书后插图。
- **各章的参考文献是英文原版的扫描图**（37 张、1290 行）：逐行排进行格，按版心宽缩放；以前当插图排时被移到书末，现在排在各章原位。
- 图下的“注：”“资料来源：”电子书排成引文段，并进图注（`fig_note_re`）；表题在表上（`cap_top_re`）。
- 第一章附录里一连串大图、表（表 A1.1、A1.2，图 A2.1、A3.1—A3.8）和正文里几幅放不进空处的图移到书末（书后插图 1—18，一页一图，与正文双向链接）；表 A1.1 两张、图 A2.1 三块分在一起（`plate_figs`）。
