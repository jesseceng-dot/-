# 《中国哲学简史》：转换说明与验收

源文件：EPUB（冯友兰 著，涂又光 译，北京大学出版社 2010），`source/zhongguo-zhexue-jianshi.epub`；成品：`out/16k/18-中国哲学简史.pdf`（234 页）。

## 1. 底本与改动

- 电子书是 calibre 从 Kindle 版转出的，之后有人补过图：6 幅用 LaTeX 重画的矢量图（兑卦、阳爻、阴爻、四象之阳、四象之阴，以及邵雍的两仪四象八卦图）。原来那幅八卦图的扫描件（`00030.jpeg`）各标签下的爻线不对——全画成连线，位置也错；正文引用的是重画的矢量图，PDF 用的也是它。
- **按要求没有通读校订。** 改动只有转换时发现的 5 处，PDF 里只出现改后的文字，逐条列在 [`errata/18-中国哲学简史.md`](errata/18-中国哲学简史.md)（规则在 `tools/bk_fixes.py` 的 `FIXES['q18']`）：
  - 版权页“电子信箱:fd@…”的半角冒号改全角（与上一行一致）；
  - 西文姓名缩写里的全角句点改半角（“E．R.Hughes”→“E.R.Hughes”，A.W.Hummel、S.C.Northrop、C.A.Moore 同此，与书中“H.F.Mac Nair”的写法一致）；
  - 自序注释“circa100 B.C.”漏空格；
  - 第十六章末“【注】 关于中国人的民族观念”是一节的标题，电子书排成了加粗正文，这里排为小节标题（进目录）；
  - 第二十三章“十二主卦”圆图：正文说“顺序如下（由中看起，顺时针方向）：”，下一段接着说“这个序列……”，电子书却把图排在下一段之后；这里把图移到冒号之后。
- 其余（包括“Peiping:Allen and Unwin”这类引文格式问题）保持原样。

## 2. 版式与结构

- 版式与本仓库其余 16 开书相同：页面 481.89 × 680.31 pt，正文思源宋体 10.5 pt，每页 32 行 × 34 字、行距 17 pt，整页末行基线 615.0 pt。
- 顺序：封面 → 书名页（原书书名页图）→ 版权页 → 目录 → 自序（及其注释）→ 正文 28 章 → 注释。电子书自带的目录页只列章，不排；目录按标题重新生成，列章、节两级，页码可点击。
- **章题**：一行排得下的章题排一行；排不下的三个（第十二、十七、二十四章）章号单独一行，章名完整排在下面，不把“将汉帝国理论化的哲学家”这样的词组拆开。
- **引文**：电子书的引文段（小字灰色）排楷体，诗句一句一行，出处右对齐。
- **注释**：共 12 条（自序 3 条，正文 9 条）。自序的注释排在自序后；正文各章的注释按章分组，集中排在正文之后。页内角标 `[n]` 与注释互相链接。
- **行内小图全部转成文字**（70 处，33 幅不同的小图）：
  - 生僻字 7 个：𤴯（疒丸，U+24D2F）、𢜔（知心，U+22714）、乂（U+4E42）、𬘡（纟因，U+2C621）、𫍰（讠思，U+2B370）、𮭨（晏鸟，U+2EB68）、㑺（亻隽，U+347A）。先按字形查汉字构形数据（cjkvi-ids）定码位，再逐个对照上下文核实：《庄子》“以死为决𤴯溃痈”、《墨经》“𢜔也者，以其知论物”、《洪范》“从作乂”、《系辞》“天地𬘡缊”、《荀子·乐论》“使其文足以辨而不𫍰”、向秀郭象注“斥𮭨之能下”、《世说新语》“时贤㑺之士”。思源宋体没有 𤴯、𫍰、𮭨 三字，就用它自己的笔画拼成（𤴯 = 疔的“疒” + 纨的“丸”；𫍰 = 谌的“讠” + 腮的“思”；𮭨 = 鷃的“晏” + 鹌的“鸟”），与正文字形一致（`tools/fonts.py`）。
  - 卦爻符号 25 个：八卦 ☰☱☲☳☴☵☶☷，六十四卦中的乾坤屯 ䷀䷁䷂ 和十二辟卦 ䷗䷒䷊䷡䷪䷀䷫䷠䷋䷓䷖䷁，阳爻、阴爻、四象之阳、四象之阴 ⚊⚋⚌⚍。每幅图由程序逐条判断是连线还是断线，再换成对应的 Unicode 码位；码位又用两种字体的字形反查了一遍，并与正文提到的卦名一一相符。卦爻字形用霞鹜文楷的（满一个字宽，与原书图样最接近）。
- **插图**：邵雍两仪四象八卦图（矢量图）和十二主卦圆图（扫描图），留在正文原处，按原书扫描的分辨率（300 dpi）定大小，图中标签约与正文同大。两幅图都没有造成页底留白，所以没有书后插图。
- 链接：259 个书内链接（目录、书签、注释角标与回链）。

## 4. 这次顺带修好的排版流程问题（对以后重排的各册同样有效）

- **注释角标前的空隙**：角标前加的“词连接符”（U+2060，防止角标与前一个字分到两行）在 Chromium 打印成 PDF 时被画成一个空格宽的字形，角标因此右移约 1.8 pt，“[1]”前留出一道缝、后面贴着下一个字；ISBN 里连字符后也多出空隙。分行已经由排版程序决定，打印时就把它去掉了（`tools/render.py`）。以前交付的各册也有这个现象（只是角标位置，不影响分行和页码），重新打印即可消除。后来已按用户要求重印（杜威各册除外），见 `docs/转换手册.md` 第 7 节。
- **单独成行的段尾**：段落拆页后只剩一行时，排版程序原来只在出现页底空白时才放宽字距档，现在遇到段末单行、段首单行也会再试一次（`tools/book.py`）。本书第二十四章有一处段末“了。”两个字单独落到下一页页首，就是这样消除的。
- **斜体西文词之间的空格**：电子书把书名的每个词分别排成斜体（`<i>A</i> <i>History</i> …`），词间的空格原来会被当成多余空格删掉（“AHistoryofChinesePhilosophy”），现在保留（`tools/bk_text.py`）。已核对以前交付的各册没有这种写法，不受影响。
- **长章题的换行**：见上文“章题”（`tools/normalize.py`）。
