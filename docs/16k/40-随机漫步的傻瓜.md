## 2. 版式与结构

- 版式与本仓库其余 16 开书相同：页面 481.89 × 680.31 pt，正文思源宋体 10.5 pt，每页 32 行 × 34 字、行距 17 pt，整页末行基线 615.0 pt。
- 顺序（与电子书相同）：封面 → 书名页 → 版权页（电子书的两页：CIP 数据和版权、出版信息，合成一页照录）→ 目录 → 各方赞誉 → 专家推荐 → 自序 → 前言 → 三篇（14 章）→ 后记 → 注释（4 条，其中前言 1 条，排在全书最后）。
- 篇页：篇名（“第一篇”和篇名，第二篇另有副题“——存活者偏差及其他”）和电子书的题词；随后是这一篇的导言（电子书里接在题词之后、没有标题的几段），再是各章。导言不单独作书签和目录条目，页眉用篇名。
- 电子书每个标题后面都有灰色的原书名“Fooled by Randomness”作装饰，不排；第八章标题“太多“下一个富翁””在电子书里断成两行，接成一行。
- 节下的小标题作第四级标题；电子书排黑体的几句话（以“。”结尾的）仍作正文段落，排黑体。推荐语、序言的署名右对齐（署名楷体，人名黑体）。
- 表题排在表上，图题排在图下；6 幅图和表格图片留在原位。
- 目录列篇、章、节三级，页码可点击；书内链接 87 个，外部链接 3 个；书签 70 个。

## 4. 这次顺带加的功能（都要在 `CFG` 里打开）

- `part_intro`：部分（篇）名之后、第一章之前没有标题的几段，作这一部分的导言排在部分页之后，不单独作书签和目录条目，页眉用部分名。第 38 册同样用了。
- `notes_end='all'`：前言的注释也和正文的注释一起排在全书最后（见第 36 册说明）。
