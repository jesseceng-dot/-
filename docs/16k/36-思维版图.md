## 1. 底本与改动

- **按要求没有通读校订。** 转换时没有发现需要改的明显错误，勘误表 [`errata/36-思维版图.md`](errata/36-思维版图.md) 是空的。
- 第 2 章“中国（China就是‘middle kingdom’，其实质上的含义是指‘世界的中心’）”的括号在整句之后才闭合，读得通，照原样。

## 2. 三册共同的做法

- 版式与本仓库其余 16 开书相同：页面 481.89 × 680.31 pt，正文思源宋体 10.5 pt，每页 32 行 × 34 字、行距 17 pt，整页末行基线 615.0 pt。
- 每册的封面用电子书里这一册的封面图；书名页按每册的书名、译者排；版权页用电子书唯一的一页版权信息（“认知三部曲（全三册）”、电子书编辑、出品与发行单位），三册相同，整页照录。合集的封面用电子书的套装封面。
- **西文人名中间的间隔号“·”不再落在行首或行尾**（这一批新加的 `name_dot`，见第 4 节）：以前各册，引文和注释里的“卡尔·皮尔逊”这样的名字偶尔断成“卡尔 / ·皮尔逊”。
- 注释：每册的注释都集中排在书末一处（`notes_end='all'`），按章分组，角标与注释双向链接。
- 插图留在原位，图注在图下；没有图因页底留白而移到书后。
- 目录列章、节两级，页码可点击，空行固定。

## 3. 《思维版图》的版式与结构

- 顺序（与电子书相同）：封面 → 书名页 → 版权页 → 目录 → 序言 → 正文 8 章 → 结束语 → 致谢 → 注释（2 条）。
- 章内的节标题、小节标题各用自己的字体；引文段排楷体，引文的出处右对齐。
- 13 幅图（道教符号、实验图片等）留在原位，图注在图下。
- 书内链接 55 个，外部链接 2 个（版权页的网址）；书签 48 个（章、节两级）。

## 4. 这次新加的功能（对以后各册同样有效，都要在 `CFG` 里打开）

- `name_dot`：正文和注释里夹在两个字之间的“·”两边加不占宽度的词连接符（U+2060），人名、书名（《论语·子路》）不在“·”处断开；段首的“·”（列表项的项目符号）不加。第 36–40 册都打开。以前交付的各册没有这样处理：16 开第 1–35 册约 270 处、黑格尔、康德、杜威各册约 70 处人名在“·”处断开（页内的行首、行尾；跨页的没有算），是否重排等用户决定。
- `notes_end='all'`：书前部分（序言、前言）、正文、书后部分的注释全部排在全书最后一处。
- `tools/bk_collection.py`：一个电子书里的几本书各成一册之后，再拼一个合集（封面 + 总目录 + 各册）。总目录列每册的书名（注明全书页数）和各章，书里分“部分”的列出部分和其下各章，页码用各册自己的页码，条目可点击；合集书签把每册的书签放到这一册名下。

## 6. 复现

```

BOOK_SCRATCH=<dir>/q36 BOOK_GEOM=k16 BOOK_FONT_DIR=<dir>/q36/fonts python -m tools.bk_build 36
BOOK_SCRATCH=<dir>/q36 BOOK_GEOM=k16 BOOK_FONT_DIR=<dir>/q36/fonts python -m tools.bk_report 36
BOOK_SCRATCH=<dir>/q36 BOOK_GEOM=k16 BOOK_FONT_DIR=<dir>/q36/fonts python -m tools.bk_errata 36

```
