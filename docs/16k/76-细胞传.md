# 《细胞传》：转换说明与验收

源文件：AZW3（〔美〕悉达多·穆克吉 著；中信出版集团，见识城邦；原书 The Song of the Cell: An Exploration of Medicine and the New Human），`source/xibao-zhuan.azw3`；成品：`out/16k/76-细胞传.pdf`（436 页，8.5 MB）。电子书没有版权页，也没有写出译者（书末“译者注记”未署名），所以书名页只列作者；出版社取自译者注记里的“中信出版集团见识城邦的编辑团队”。

编号：这次交来三本，按上传的先后，《轴心时代》作第 75 册，这一本作第 76 册，《AI 3.0》作第 77 册。

## 1. 底本与改动

- **按要求没有通读校订。** 转换时改了 5 条规则，列在 [`errata/76-细胞传.md`](errata/76-细胞传.md)：注释和参考文献里西文的逗号、分号、冒号、句点、名字缩写之后，以及篇名的引号前后漏的空格（“Ackerknecht,Erwin Heinz.Rudolf Virchow:Doctor,Statesman” → “Ackerknecht, Erwin Heinz. Rudolf Virchow: Doctor, Statesman”），全书约一千处；网址里的不动（“…%20is,highly%20…”）。
- 电子书结构上的毛病，转换时改了，不改文字：
  - 每个标题都拆成两个文件（“第一章”一个、“原始的细胞：隐形的世界”一个；“第一部分”“发现”；“序言”“‘生物体的基本粒子’”），这里合成一个标题：章名两行（序号在上），目录里一行；
  - 注码图标前电子书留了换行，排出来注码前多一个空格，行会在注码前断开（注码和后面的“，”“。”落到行首）。现在注码紧接前面的字；
  - 5 个注码（[89] 等）电子书排成了单独的一段，并回前一段末尾；
  - 作者的 14 条注（“[1]……——作者注”，纸书的页下注）电子书放在正文里，注码和注文都只链接到自己：这里注码链接注文、注文链接回注码，注文收进本章注释（排在本章注释的开头）。
- 其余照原样。

## 2. 版式与结构

- 版式与本仓库其余 16 开书相同：页面 481.89 × 680.31 pt，正文思源宋体 10.5 pt，每页 32 行 × 34 字、行距 17 pt，整页末行基线 615.0 pt。
- 顺序：
  - 封面 → 书名页 → 目录 → 献词 → 题词页（史蒂文斯、尼采的两段，题词的注随后）；
  - 序言 → 引言 → 第一—六部分（第一—二十二章；部分页之后是该部分的导语）→ 后记；
  - 致谢 → 译者注记 → 参考文献（悬挂缩进）→ 图片来源。
- 电子书所有段落都是同一个类，样式写在段内的 `<span>` 上：这里按 span 的类排（`bk_extract.SPAN_PCLS`）。章首题词楷体，出处（“——华莱士·史蒂文斯”及第二行）右对齐；正文里的引文楷体；献词居中。
- 注释：多看格式，注码是小图标，注文在各章末尾。电子书的注号全书连续（[1]–[1013]），这里照用，连同作者注共 1027 条，排在各章之后，双向链接。
- 插图：正文里 23 幅留在原位，图说（电子书与引文同一个类）在图下；第十章之后的 18 幅彩插（“▲1 埃米莉·怀特黑德……”）一页一图，排在第十章之后（“插图”，第 195–212 页）。没有图造成页底留白，所以没有书后插图。
- 第十八章“编号为410的一只白色㹴犬”的“㹴”，电子书是一个 SVG 小图，转成字。
- 书内链接 5196 个，书签 63 个。

## 4. 这次加的功能

- `bk_extract.SPAN_PCLS` / `SPAN_CAP`：段落样式在段内 span 上的书；紧跟在图片后面的这一类段落是图注。
- `bk_extract.SELF_NOTES`：注码和注文各自链接到自己时，按锚点的对应关系互链。
- `mark_para_join`：只有注码的段并到前一段。
- `head_join` 也合并分在两个文件里的“序号”与“标题”。
- 多看注码图标前的空白去掉；多看注释条目以“[n]”开头时用它作注号；网址的最后 3 个字符不单独断到下一行。
