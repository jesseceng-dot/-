# 《这才是心理学》勘误表

底本是一份已经通读校订过的个人校订本（21 条“校订注”排在相关段落之后，注释里的校订也照排）。按要求没有再全面校订；这里只有转换时发现的排版问题。

改正的问题共 **8** 条（每条是 `tools/bk_fixes.py` 里的一条改正规则，抽取电子书文字时应用；生成时逐条核对：全部规则都在原文中找到并已应用）。“原文”是电子书里的文字（为便于定位，常连同前后几个字一起列出），“改为”是 PDF 里的文字；“全书”一节的规则对每一章都适用。
