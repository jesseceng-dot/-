# 《知识的错觉》：转换说明与验收

源文件：EPUB（〔美〕史蒂文·斯洛曼、〔美〕菲利普·费恩巴赫 著，祝常悦 译；中信出版社 2018；原书 The Knowledge Illusion: Why We Never Think Alone），`source/zhishi-de-cuojue.epub`；成品：`out/16k/31-知识的错觉.pdf`（193 页，2.4 MB）。

## 1. 底本与改动

- **按要求没有通读校订。** 转换时改了 4 处，列在 [`errata/31-知识的错觉.md`](errata/31-知识的错觉.md)：版权页原书名里的全角冒号改半角；第一章一处问句的半角问号改全角；第十一、十二章两处注码后多余的空格。
- 另有电子书的标记错误按原意改正，不改文字：作者注的注码是裸数字链接，有的链接把后面一整句也包了进去（“3 2010年，他直接……”），这里注码照常上标，句子回到正文。
- 章名在正文和编者注里写作“第一章　我们知道什么”，在电子书的注释里写作“第一章 我们知道什么”；这里统一用全角空格（“推荐序”“前言”“结语”后也一样）。
- 其余照原样。

## 2. 版式与结构

- 版式与本仓库其余 16 开书相同：页面 481.89 × 680.31 pt，正文思源宋体 10.5 pt，每页 32 行 × 34 字、行距 17 pt，整页末行基线 615.0 pt。
- 顺序：
  - 封面 → 书名页 → 版权页（电子书书末的 CIP，按惯例挪到书名页之后）→ 目录；
  - 推荐序（尤瓦尔·赫拉利），末尾的署名、头衔右对齐；
  - 正文：前言和十二章，结语；6 幅图（马桶示意、两幅自行车、运动轨迹、硬币、一张问答正确率表，都是图片）留在原位；
  - 书末：编者注、致谢、注释。
- **两套注释**：
  - 编者注、译者注 22 条（电子书里是每章末尾的 [n]，内容是换算、译名、原文的说明，条末各自注明“——编者注”“——译者注”）：角标排成 ①②③，按章分组集中在书末“编者注”一节；
  - 作者注 224 条（电子书书末的“注释”，按章编号）：角标排成 [n]，按章分组排在书末“注释”一节；
  - 两套都与角标双向链接。
- 目录列章、节两级，页码可点击，空行固定。
- 书内链接 1303 个；书签 73 个。

## 4. 这次顺带加的功能（对以后各册同样有效）

- `note_group_h`：书末注释部件里用 `<h3>` 分章的，每章一组。
- 抽取：裸数字注码的链接把后面的正文也包进去时，拆开（只拆“数字＋空格＋正文”这种形式）。
- `qa_marks` 认得书末 `(n, 'notes')` 一节里的注释段。
- `head_sub` 也作用于书末注释的分组小标题。
