## 2. 版式与结构

- 版式与本仓库其余 16 开书相同：页面 481.89 × 680.31 pt，正文思源宋体 10.5 pt，每页 32 行 × 34 字、行距 17 pt，整页末行基线 615.0 pt。
- 顺序：
  - 封面 → 前勒口（作者简介）→ 书名页（电子书自带的书名页图）→ 版权页 → 目录；
  - 卷首插图 5 幅（大英帝国人口统计图、昌迪加尔公寓大楼、简·雅各布斯、列宁著作书影、罗莎·卢森堡），一幅一页，图说在图下；
  - 题词（献给路易斯，以及布赖恩·福瑞尔《翻译》里的一段对白）→ 中文版序言；
  - 正文：导言，然后四个部分共十章；
  - 书末：鸣谢、插图来源、索引、再版译者后记；
  - 后勒口（译者简介）→ 封底。勒口和封底都是电子书自带的图片。
- **版权页**：电子书把版权信息分在两处，开头是英文原版的版权说明和“青年创新基金”标志，书末是 CIP 数据。这里合成一页：CIP 在上，原版说明和标志在下。
- **部分页**：每个部分单独一页。第三部分在部分名后有七页导言，接在部分页后面，导言的注释排在导言之后。
- 目录列章、节两级，页码可点击；空行固定，各页疏密一致。
- **标题**：太长的章名把章号单独排一行（“第四章”在上，“极端现代主义的城市：试验与批评”在下）；带冒号的长节名在冒号后分行。
- **题词**：章首、节首的引文排楷体，出处右对齐，紧跟在引文下面。第一章、第四章开头的版面要靠留空才能排满，空行放在“引文＋出处”这一组的下面（最多两行），不放在引文和出处之间。
- **注释**：896 条，原书在每章末尾，这里也排在每章之后，与角标双向链接。
- **插图**：正文 37 幅，都留在原处，图题在图下。六幅图下面有图例（如图 4-5 的“A.三权广场；B.政府各部……”、图 8-4 的图标说明），电子书把它们排成了引文段落；这里把图例和图题一起排在图下，不与图分开。没有图造成页底留白，所以没有书后插图。
- **表格**：表 6-1 及续表，三栏文字表格，表头加粗。
- **行内小图**（3 个，都已转成文字）：
  - 第一章，一个法文词的图片：“主人”（maître）；
  - 第九章，引《庄子·养生主》“技经肯綮之未尝，而况大𮝴乎”，图片上是“车”旁加“瓜”的字，即“軱”的类推简化字 𮝴（U+2E774）。字库里没有这个字，用思源宋体里“轱”的车旁和“呱”的瓜旁拼成（`tools/fonts.py` 的 `compose_gu`），和正文同一字体、同样粗细；
  - 第九章，修补者的公式小图画的是“4264 (°C)²”，替代文字是“4264平方摄氏度”。上下文是“当日平均气温的平方和达到……时”，这里按替代文字排“4264平方摄氏度”。
- **索引**：照电子书排成两栏，页码保留英文原著的页码，索引开头有电子书原有的说明“（索引页码为英文原著页码）”，页码不可点击。没有换算成本书页码，原因是：
  - 电子书里没有标出原书页码的位置（第 23 册有，所以那本能逐条换算）；
  - 索引词条是英文，中文正文里只有译名，很多译名和词条对不上；
  - 有大量指向注释的页码（如“380n45”）。
  
  勉强换算会有很多条指错页，不如保留原样。这与第 21 册的做法相同。**需要用户决定**：如果希望索引指向本书页码，可以只换算能在正文里唯一找到译名的那部分词条，其余保留原页码并注明。
- 链接：书内链接 4554 个；书签 78 个。

## 4. 这次顺带加的排版功能（对以后各册同样有效）

- `front_flaps`、`back_flaps`：勒口图片排在封面之后、封底之前，各占一页。
- `copyright` 可以是几个部分的列表（合成一页版权页），`copyright_imgs` 指定版权页上标志图片的高度，`copyright_top` 指定上方留几行。
- `open_air=2`：章名下面的第一段最多可以下移两行；引文的出处紧跟引文，需要留空时留在“引文＋出处”的下面（最多两行）。
- 用 `text_map` 把图下的图例段落归为图题（`('cap', 0, 0)`），与图片排在一起。
- `fonts.compose_gu`：用字体自己的部件拼出 𮝴。
