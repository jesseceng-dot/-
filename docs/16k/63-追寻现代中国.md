# 《追寻现代中国：1600—1949》：转换说明与验收

源文件：AZW3（〔美〕史景迁 著，温洽溢 译；四川人民出版社 2019，理想国；原书 The Search for Modern China），`source/zhuixun-xiandai-zhongguo.azw3`；成品：`out/16k/63-追寻现代中国.pdf`（564 页，16.3 MB）。

编号：这次交来三本，按上传的先后，《身份政治》作第 62 册，这一本作第 63 册，《中国国家治理的制度逻辑》作第 64 册。

## 1. 底本与改动

- **按要求没有通读校订。** 转换时改的都是标点和空格（5 条规则），列在 [`errata/63-追寻现代中国.md`](errata/63-追寻现代中国.md)：
  - 注释和延伸阅读书目里西文逗号、冒号、分号后漏的空格（“Ann Arbor: University”“Press, 1963”“Peach Blossom Fan, Berkeley”），一条规则，全书一百六十余处；
  - 西文书目里一个全角逗号、一个全角冒号改半角；两个中文书名里的半角冒号改全角（“《翻身：一个中国农村的革命纪实》”）；“2vol.”漏的空格。
- 其余照原样。延伸阅读书目里电子书带着两个注码和两条注（[1] 是一条出处；[2] 的注文读起来像书目正文错放进了注里），照电子书排在书目之后的“注释”里，没有改动。

## 2. 版式与结构

- 版式与本仓库其余 16 开书相同：页面 481.89 × 680.31 pt，正文思源宋体 10.5 pt，每页 32 行 × 34 字、行距 17 pt，整页末行基线 615.0 pt。
- 顺序：
  - 封面 → 理想国的标识页和“想象另一种可能”页（各占一页）→ 书名页（电子书的书名页是文字，按书目信息排）→ 版权页 → 目录；
  - 总序（郑培凯、鄢秀《妙笔生花史景迁》，四节）→ 献词 → 第一版序、第二版序、第一版致谢、第二版致谢；
  - 第一部至第四部，每部一个部分页，后面是该部的导言，再是各章（共十八章）；
  - 延伸阅读书目 → 理想国二维码页 → 封底。
- 各章：章名“第一章　晚明”，节名是二级标题；引文（电子书的仿宋）排成楷体；译者在括号里补的说明（电子书的楷体，“（即《大义觉迷录》……）”）照样用楷体；署名右对齐。
- 注释 332 条：每章从 [1] 编起，与角标双向链接，排在章后，相邻的短章合成一组。
- **四组插图**：电子书把纸书的四组彩插（42、21、26、15 幅：书画、版画、照片）放在第六、十一、十六、十八章的末尾。这里整组排在该章（及其注释）之后，一页一图，图注在图下，长图注在版心里折行（楷体），每组第一页加标题“插图一”至“插图四”，目录、书签里都有。
- 正文里的地图和画成图片的表格留在原位：
  - 表题（以及“（1945年9月=100）”这样的副题）在表上，随表浮动；表下的“（1）……”“注：……”随表；
  - 表题与下一张表紧挨时（“1902—1936年各国在华的投资”“1936年各国在华的制造业投资”），各归各的表；
  - 按 150 dpi 定尺寸；没有图造成页底留白，所以没有书后插图。
- 延伸阅读书目按章分组（小标题“第一章　晚明”等），条目的类别名（“明代社会”）加粗；书名斜体。
- 目录列部、章两级（每章的节不进目录，与电子书的目录相同），页码可点击。书内链接 1704 个，书签 143 个。

## 4. 这次加的功能（对以后各册同样有效，都要在 `CFG` 里打开）

- `cap_top_all`：图前接连的几行图题都算这张图的（表题和它的副题）；`cap_below_re`：图后的图注只认符合这个正则的（“（1）”“注：”），其余留给下一张图作表题。
- `notes_before_plates`：`insert_plates` 的插图组排在该章的注释之后（以前要看注释是否攒够一组，有时排在注释之前）。
- `hyph=(最短词长, 遍数[, 余量])`：西文断词更积极（这本书 6 个字母、3 遍），用于大段西文书目；默认（8、1、0.4）与以前相同。这些设置现在也算在排版缓存的键里。
- 共用的改动：图版页（一页一图）的图注改为在版心宽度里折行，按行数留出位置，词连接符不再印出（以前长图注在整页宽度里折行，见总汇报）。
