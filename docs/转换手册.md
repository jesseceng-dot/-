# 电子书 → 出版级 PDF：转换手册

本手册汇总了这个仓库里全部已完成的转换：《贺麟中译黑格尔经典著作》4 册，《康德文集》10 册，《杜威著作精选》11 册，16 开第 1–10 册和第 16、17、18 册。内容包括这些转换的做法、出过的问题和修正办法，目的是让下一本书一次排好。

**用法**：每次转换前先读第 1 节（要求）和第 3 节（流程）；遇到问题查第 4 节；交付前把第 6 节的清单逐项核对一遍。这里提到的脚本都在 `tools/` 下，用 `python -m tools.<名字>` 运行。

## 1. 要求总表（以用户原话为准；后提的要求覆盖先提的）

### 1.1 第一次提出的转换要求（一直有效）

1. 正式的页面尺寸、字号和正文字体（可沿用原书，也可换更适合出版的字体），左右页边距相同。各级标题用不同字体，而且都不能与正文相同。其余尽量沿用原书样式和排版（包括分页设定）；原书排版明显不合理的，自行处理。
2. 题词、引文出处、署名、人名、日期等独立短行，对齐方式要合理（**强制检查**）。
3. 非行内的大插图、表格：最初的规则是一律放到书末，正文原处只留带黄色边框的蓝字“见书后插图N”，可点击跳转，并与原书的图注同页。书末一页一图，按正文字号合理缩放，页底附返回链接。行内插图不得撑大行高。（这一条后来有调整，见 1.2。）
4. 行内代替文字、符号、公式的小插图，以及行间的公式类小插图，凡能精确转成文本的都转成文本，**一定要精确**。
5. 合集按书一本一本生成；每本按正文前、正文、正文后的顺序；正文按章、节顺序。

验收标准：

1. 正文前后的版权、目录、前言、附录、索引等模块，细节排版要符合正式制式。
2. **（强制）** 每章、节连续文本的页底，文字基线必须对齐，连续页面的页底不允许留任何空白，只有章节末尾可以自然留白。任何标题都不能落在页面最后一行。可以微调行距、标题距离、字距来解决，但所有调整都要肉眼难以察觉。
3. 原书所有链接和封面都保留，包括第一页的封面。换行的长标题每行字数要合理美观。所有文本的对齐方式都要检查有无错误。
4. 连续行的行末不许出现空白；如果是行内插图造成的，就把图转成文字后重排，或微调字距。单独的角标、标点、符号不许被挤到下一行单独成行；不许一两个字被挤到下一页单独成页。
5. 不因转换误删原书的排版、样式和字符。要特别保护“标题序号”与“标题正文”之间的视觉间隔，防止空格被 HTML/CSS 规范化、trim、DOM 重构或渲染器吞掉。不合规范或明显错误的地方，仔细检查后可以合理处置。

返工原则：验收出问题，只在出问题的章、节或模块里单独修改重排，不全书重排，最后合并成全书。

## 2. 标准版式（16 开，`BOOK_GEOM=k16`）

| 项目 | 规定 |
|---|---|
| 页面 | 481.89 × 680.31 pt（170 × 240 mm）。Chromium 打印时会把页面四舍五入，生成后逐页把页面框改回这个精确值（上边不动，基线不受影响） |
| 版心 | 宽 357 pt，每行 34 字；左右页边距相同，各 62.4 pt；天头 76 pt；每页 32 行，行距 17 pt；整页末行基线 **615.0 pt** |
| 正文 | 思源宋体（Noto Serif CJK SC），10.5 pt（五号） |
| 引文 | 楷体（霞鹜文楷）10 pt，左右各缩进两字 |
| 注释、版权页、图注 | 8.5–9 pt，排在 47 行的小字行格上，末行基线仍是 615.0 pt |
| 标题 | 最多九级，每级一个字体族，都与正文不同：一级思源黑体粗 17 pt，二级霞鹜文楷粗 14 pt，三级文泉驿正黑 12 pt，四级文鼎楷体粗 11 pt，五级文鼎报宋粗，六级文泉驿微米黑粗，七级文鼎明体粗，八级文鼎简中楷粗，九级 Droid 粗（`tools/style.py` 的 `.s-h1`–`.s-h9`）。没有粗体的字体用 `fonts.embolden` 做出真粗体，不用合成粗体 |
| 西文、希腊文 | Noto Serif；斜体用 Noto Serif Italic |
| 页码 | 封面不编页码；正文前用小写罗马数字；正文从 1 起用阿拉伯数字。PDF 的页码标签、书签与目录一致 |
| 页眉 | 双页书名、单页章名（前置部分用模块名） |
| 链接 | 书内链接（目录、书签、注释角标与回链、插图往返）一律有效；外部链接排成蓝字 |
| 顺序 | 封面 → 书名页 → 版权页 → 目录 → 前置（序、导言等，罗马页码）→ 正文 → 注释 → 附录等后置 → 书后插图 → 二维码页或封底（原书有才排） |
| 字体嵌入 | 全部是 TrueType 子集，**不允许 Type3 字体**：CFF 格式的 Noto CJK 先子集化，再转成 TrueType 轮廓 |

另外两套旧版式：黑格尔、康德、杜威各册用大 32 开（`BOOK_GEOM=d32`，397 × 575 pt，27 行，末行基线 516.0 pt），引擎是同一个。

## 3. 工作流程

### 3.0 准备

- 先确认要求：这本书要不要校订，有没有它自己的要求（见 1.2）。
- `$Q` 是这本书的工作目录（放在临时目录下，命名为 `qNN`），`NN` 是书号。`BOOK_SCRATCH` 的目录名（如 `q18`）同时是 `tools/bk_fixes.py` 里 `FIXES` 的键。临时目录会随会话消失，所以要留下的东西（配置、规则、文档、成品）都要进仓库。

### 3.1 识别与解包

1. 看 OPF 元数据，弄清书名、作者、译者、出版社、ISBN；把源文件复制到 `source/<拼音名>.epub` 或 `.azw3`。
2. 解包：EPUB 用 `BOOK_SCRATCH=$Q python -m tools.epub_unpack <book.epub>`，AZW3 用 `tools.unpack`。解出来的部件在 `$Q/unpack/x/mobi8/OEBPS/Text/partNNNN.xhtml`，图在 `…/Images/`，EPUB 原件在 `$Q/epub_raw/`。
3. **预检**：`BOOK_SCRATCH=$Q python -m tools.preflight`。它一次列出：
   - 部件、标签与类的统计；
   - 注释形式（角标、注释条目、回链、`<aside>`）；
   - 每张图的尺寸、分辨率、用了几次、在哪里用（夹在文字里的小图要转写，独立成段的是插图）；
   - 未被引用的图；电子书自带的字体和私用区字符、`NFDA` 缺字占位符；
   - **正文、标题、引文字体缺的字**；
   - 标点和空格的机械问题。
   配置写好后再跑一次 `--book NN`，确认小图全部标为“✓ 已转写”。

### 3.2 配置（`tools/bk.py` 的 `CFG[NN]`，各项见附录 A）

- **部件分配**：`copyright`（CIP 页部件）；`front=[(部件, 类型)]`，类型有 text / dedication / kaitext / kaibody / figure；`body=[部件或部件组]`，一组即合成一章；`back=[部件或 (部件, 'figpages'|'noindent')]`。电子书自带的目录页不排，目录按标题重新生成。
- **段落类 → 样式**：`cls_quote` 引文、`cls_right` 署名与出处、`cls_center`、`cls_cap` 图注、`note_cls` 注释段、`head_cls` 用段落排的标题等。
- **小图转写**：`img_text={'图名': '字' | ('字', 'css类') | [片段…]}`（方法见 4.3）。
- **插图**：`fig_inline=True` 时图留在原位（现行），`fig_dpi` 按扫描分辨率定印刷尺寸。
- **规范化与改错**：写进 `tools/bk_fixes.py` 的 `FIXES['qNN']`（格式见附录 B），在抽取时生效，电子书原件不动。

### 3.3 字体

```
# 解包之后（子集要用这本书的文字）：全部字体一次生成——正文与黑体子集、各级标题字体子集、真粗体、楷体与 Noto Serif
BOOK_SCRATCH=$Q BOOK_FONT_DIR=$Q/fonts python -m tools.fonts --shared
# 以后只重建本书的正文与黑体子集（先删掉旧文件）：
BOOK_SCRATCH=$Q BOOK_FONT_DIR=$Q/fonts python -m tools.fonts SerifSC-Regular SerifSC-Bold SansSC-Regular SansSC-Medium SansSC-Bold SansSC-Black
```

子集包含这本书 XHTML 里的全部字、`bk_fixes` 的替换文字、`img_text` 的转写文字，以及 GB2312 一、二级字。预检报出的正文字体缺字，要在这一步解决（见 4.4）。**改了转写或勘误、引入了新字，必须删掉旧的子集重新生成**：`build()` 遇到已有的文件会直接跳过。

### 3.4 生成与验收

```
export BOOK_SCRATCH=$Q BOOK_GEOM=k16 BOOK_FONT_DIR=$Q/fonts
python -m tools.bk_build NN          # → $Q/out/bNN.pdf（并检查插图是否造成页底留白，有就移到书末，再排）
python -m tools.bk_report NN         # 验收数字（见第 5 节），写 $Q/out/report.json
python -m tools.qa_pdf $Q/out/bNN.pdf   # 行格、页底留白、词连接符
python -m tools.qa_marks NN          # 注释角标与注释条目一一对应
python -m tools.sheet $Q/out/bNN.pdf $Q/s1.png --pages 1-80 --cols 10 --dpi 30   # 逐页看缩略图
python -m tools.sheet $Q/out/bNN.pdf $Q/g.png --find '𤴯䷀…' --dpi 250           # 转写字符的特写
```

**目检**（脚本查不出来的问题，每本都要看）：
- 全书缩略图逐张看一遍：页底留白、标题位置、插图位置、空页。
- 放大看：版权页、目录首页与末页、第一章首页、注释页、每一幅插图所在页、每一个转写字符和符号所在的行、断成两行的长标题、表格页。

### 3.5 修改与回归

- 问题定位：`python -m tools.modplan NN partNNNN` 能看出一章的分页计划（哪段的哪几行在哪页、用了哪档字距）。
- 排版结果按模块缓存（`$Q/cache`）。缓存键由模块内容加 `layout/style/hyph/measure/typeset/model/book.py` 的代码组成；`render.py` 的修改不会让缓存失效。
- **只改打印、不改排版的重印**（第 23 册后重印早期 PDF 消除角标前的缝）：在生成那个 PDF 的提交上开一个 `git worktree`，只改 `render.py`（`python -m tools.reprint patch <目录>`），在那里照原样构建；缓存键不含 `render.py`，排版直接取自原来的缓存，分行和页码不变。再用 `python -m tools.reprint compare 旧.pdf 新.pdf` 逐页比对每行文字、基线、链接、书签和页码标签。
- 共用代码改动后：
  - 用文本比对确认这本书只变了该变的地方（`pdftotext` 前后 md5，或逐行 diff）；
  - 用 `python -m tools.bk_report` 复查；
  - 检查改动有没有影响已交付的书：只在新书配置里打开的开关（如 `lat_apos`、`li_hang`、`fig_dpi`）不影响旧书；所有书共用的改动，要确认旧书没有触发条件，或者是纯粹的改进，并在汇报里写明。

### 3.6 文档与交付

1. `docs/16k/NN-书名.md`：源文件与成品、底本与改动、版式与结构、验收表、复现命令。
2. `docs/16k/errata/NN-书名.md`：`python -m tools.bk_errata NN` 生成。没有通读校订时，在 `CFG['errata_note']` 里写清楚。
3. README 加一节（文件、书、页数，以及要点三四条）。
4. 复制成品：`out/16k/NN-书名.pdf`；源文件：`source/…`。
5. 检查：`python -m py_compile tools/*.py`；如有求解器回归测试，跑一遍；`git status` 只含该提交的文件。

| 标点前多余的空格（“一句话 。”）在空格处断行，句号落到行首（第 54 册 15 处） | `('*', re.compile(r'(?<=[汉字”’）》\]])[ \u00a0]+(?=[。，、；：！？])'), '')` |
| 段末“……注释44）。”的数字尾巴单独落到下一行 | `tail_join` 也在汉字与段末数字之间加词连接符（以前只在逗号后） |
| 私用区字符（第 54 册希腊文引文里的 U+1001A6，字体没有，会排成空白） | 按上下文改（κάλλος 的 ά），写进勘误表 |

### 4.3 行内小图的精确转写（要求 1.1 第 4 条）

1. **清点**：`preflight` 列出全部小图，带尺寸和上下文。转写之后，`bk_report` 的 `img_dropped` 必须为空（没写转写的行内小图会被悄悄丢掉，这一项就是为此加的）。
2. **生僻字**：
   - 先按字形写出构件，到汉字构形数据（cjkvi-ids，`raw.githubusercontent.com/cjkvi/cjkvi-ids/master/ids.txt`）查码位，例如 `⿸疒丸` → U+24D2F 𤴯；
   - 再对照上下文和典籍原文核实，例如《庄子》“决𤴯溃痈”；
   - 简体书优先用简化字形的码位：纟因 𬘡 U+2C621，不用 絪；
   - 码位实在确定不了的，在文档里说明依据，或者保持原图。
3. **符号**：卦象、爻、四象用程序逐条检测爻线（连线还是断线），再按六十四卦表换成 Unicode 码位，并用两种字体的字形反查核对，与正文提到的卦名一一相符。字形用霞鹜文楷（`.gua` 类，满一个字宽）。
4. **公式**：转成带上下标、根号横线的文字（`^{}`、`_{}`），分数横排 a/b；显示公式（`img_para`）居中排。图里有笔误时按上下文改，并在文档里说明。
5. **带着重号的文字**：用 CSS `text-emphasis`（字下加点）。
6. **SVG 小图**：读 `<desc>` / `alt` 再核对图形本身（第 18 册的兑卦、阴阳爻）；分隔符图排成居中文字。
7. 转写写进 `img_text`；需要另一字体的加类名（`('☰','gua')`、`('X','it')`）。下标用 `msub`、上标用 `msup`，可与 `it` 合用：`[('Q','it'), ('n','it msub')]`；撇号 ′ ″ 放在斜体里（Noto Serif Italic 有这两个字形）。
8. **LaTeX 公式小图（第 19 册，74 种）**：把全部小图连同 alt 文字放大排成一张核对表（Chromium 截图），逐个看字形：变量斜体、标签正体（XAL）、下标大小写、撇号位置；alt 只是提示，以图为准（alt“Qx（以上）”其实是 ≥ 叠在 Q_x 上）。
9. 同一张小图在不同位置意义不同（斜体字母 A 在“附录A”里是编号，在英文篇名“A Mathematical…”里是冠词）：`img_text_plain=[(前文正则, 后文正则), …]` 命中时排正体。
10. 标题里的公式小图也会转写（以前被当成标题下的插图）；小图夹在规则中间时，改正规则里用 `\0` 代表小图（`re.compile('(?<=\0),(?=\0代表)')`）。
11. 小图很多时（第 32 册 263 种）转写放在单独的模块里（`tools/bk_img32.py`），CFG 里 `img_text=…IMG_TEXT`。为了好读，转写里的上下标先写成 Unicode（CO₂、W/m²、10¹⁷），模块末尾统一换成 `msub`/`msup` 升降字（正文字体只有 ¹²³，其他上下标字符会落到别的字体）。目录、书签里的标题保留这些升降字（书签用 Unicode 上下标）。
12. 括号：有变量或乘方的式子用半角括号（与图一致：(1+r)⁻⁵⁰、(1−a)S）；夹在句中的普通算式用全角括号（照 alt）；图里的 ⋯ 写“…”；alt 里的全角“＝”统一成“=”。alt 只是提示：第 32 册“V=1 000−50/（1.05）−…”的第一项图里没有括号，以图为准。
13. 内嵌 SVG 的 `<title>` 也只是提示：第 33 册“1/250万”图里画的是 1/2,500,000，按图；标题“1015”画的是 10¹⁵。alt 齐全、数量多时（第 34 册 162 种），先由 alt 生成转写表（`tools/bk_img34.py`），再把图连同 alt 排成核对表逐个看，统一减号（−）、变量斜体（*t*、*dt*）。小标题前的小图标（第 34 册的灰色 ×、○）也转成字符。
14. **希腊文小图**（第 41–58 册，`tools/bk_img41.py`）：逐字母、逐个音调符号照图转写，原书的误印照图保留（χ 作 κ 等），不按标准拼法改；字体的异体字母在整词里排作 ρ κ θ，单个字母的小图嵌在电子书自己打出的希腊文里的，排成那段文字的字形（ϰ ϱ ϑ）。电子书修补时在一个字母的小图后又打了一遍这个字母的，`img_twin` 只排一次。放错的图（同一张图用在两条注里）按注的译文查原典排出，写进勘误表开头。

### 4.4 字体

| 现象 | 原因 / 办法 |
|---|---|
| PDF 里出现 Type3 字体（又大又糊） | Chromium 把 CFF 字体嵌成 Type3：子集化后转成 TrueType 轮廓（`fonts.otf_to_ttf`） |
| 合成粗体是 Type3 | 没有粗体的字体用 `fonts.embolden` 做真粗体 |
| 正文字体缺字（𫚉 𮭥 𤴯 𫍰 𮭨） | 用思源宋体自己的笔画拼合（`fonts.compose_*`，按构件位置取轮廓、缩放、合并），风格与正文一致；不要回落到黑体。拼合的构件字必须在子集里（GB2312 之外的，例如 鷃，要加进 `corpus_codepoints`） |
| 卦象、特殊符号正文字体没有 | 专用字体族加 `unicode-range`（`GuaSym`），只覆盖这些码位，不影响别的字 |
| 电子书自造的字 | 用电子书自带字体的字形另存一个字体（`GebRare`），放在所有字体栈最前面，并用 `unicode-range` 限定码位 |
| 行内换了字体的文字让基线偏移 0.75–1.5 pt | 行内的字体类设 `line-height:0`（`.lat`、`.gua`、`.hei` 等）；灰底框用 box-shadow 而不是 padding |
| **注释角标前出现约 1.8 pt 的缝**（U+2060 词连接符被 Chromium 画成一个空格宽，角标右移；ISBN 连字符后也有） | 词连接符只在测量分行时需要，打印的行里去掉（`render.line_div`）。在此之前交付的书大多带着这个问题，`qa_pdf` 的 joiner 一项能查出来 |
| Noto Serif 的 U+2060 字形宽 600（是 bug） | 同上：打印时不带词连接符 |
| 正文字体没有的符号（第 39 册归纳法图式里的占位方框 ❑ U+2751，电子书是图片） | 转写成文字时给这几个字加 `sym` 字体类（`[('❑', 'sym')]`）：`SymFont` 是 Noto Sans Symbols2，`unicode-range` 只含 U+2751，`fonts.SYSTEM_COPIES` 把它复制进字体目录 |
| 符号字库里都没有（第 32 册“⌟形损失函数”的 ⌟ U+231F） | 用思源宋体自己的笔画做（`fonts.compose_corner`：“」”移到基线上、放在窄一些的字宽里）。改了拼字后要删掉旧的 `SerifSC-Regular.ttf` 重新生成 |

### 4.5 排版引擎（基线网格与分页）

- 每块内容占整数个行格。整页文字的末行基线全书一致，是由求解器（`layout.solve`）从每段几档难以察觉的字距里选出组合保证的。
- 字距档位：常用档 ±0.012/0.024/0.036 em；**排不满一页，或出现段末单行（寡行）、段首单行（孤行）时，再试一次加宽档 ±0.048/0.06 em**（`book._typeset_module`）。第 18 册第二十四章的段末“了。”落页首就是这样消除的。
- 纯中文段落里，±0.012、±0.024 两档改不了行数：要让每行多容一个字，字距得紧到约 −0.029 em。所以有时要靠 ±0.036 和加宽档，或者把标题的段前空加减一行。
- 惩罚值：页底缺行 200 起；寡行、孤行各 50；段末一行只有一个标点或一个注释角标的，禁止；只有一个字的，罚 10；每章末页只剩 1–2 行，罚 300；标题后不足两行、标题落页底，禁止（标题的 keep 规则）。段末一行只剩“2006）”这样的年份、数字和括号（不超过 6 个字符）的，也禁止（第 29 册注释）。只有标点的末行（“——”“——”” 等，不超过 6 个字符）也禁止（复查时在第 4、16 册和黑格尔第 4 卷发现）；哪一档字距都避不开时，用 `normalize.KEEP_TAIL` 把末字和破折号排成一个不拆开的整体。表格单元格自己折行（`_wrap_cell`）时同样不留只有标点的一行，长公式优先在“→”“=”后折行。
- 目录末页至少留 5 行（`tail_min`）；目录组前的空行挤不下时可以收（`noshrink`，罚 80）。设了 `toc_even` 时，两行长的目录条不拆在两页（`nosplit`，第 29 册）。
- 段落之间的空行改为“下一段段前空一行”，页首自动吞掉，页底自动收缩。
- 行首行尾禁则：`line-break: normal`，引号簇不造成松行。kinsoku 必须是 0 违规。
- 两个数字之间的连接号、连字符（“1797—1798”“pp.123–132”“图7-2”“536-544”）后面加词连接符，不在那里断行（`bk_text`）；按段首文字定样式的 `text_map` 和图注文字匹配前先去掉词连接符。
- **量行（`measure.py`）怎样判断换行**：Chromium 给出每个字的框，字的中线落到下一行的位置就算换行。第 32 册之前按“离段落顶端几个行距”算，有两个毛病：
  - 一行里有着重号时，行框高出约三分之一行，下面各行整体下移；再遇到一个下移的下标（CO₂ 的“2”），就被算到下一行，那一行排出版心（第 32 册第 3 章）；
  - 在软连字符处断开的单词，下一行第一个字母报出一个跨两行的框，中线正好落在两行之间，有时被算到上一行：印出来是“Indiv / idual”“Gers / chenfeld”，不带连字符、断错了位置。复查各册时没有查这一项，第 32 册时才发现，几乎每本书都有几处（见 `docs/复查报告.md` 第 6 节）。
  现在按“离本行第一个字几个行距”判断，跨两行的框按它的下沿算。`audit_pdf` 的 split 一项查成品 PDF 里的这种断词（两个词在空格处断开的也会报出，要逐条看）。
- 注释主要是西文、按左对齐排的（`notel` 样式）默认只有一档字距，注释页可能补不满或末页只剩一行；`notel_vary=True`（第 32 册）让它们也用各档字距。
- 别无办法时，求解器会把一页的行距整体撑开（`layout` 的最后手段）：`qa_pdf` 的 grid 会报出这一页（第 34 册第 2 章首页，行距 18.8 pt），**必须找到原因消除**。办法：`epi_name_air=True`（题词出处不带“——”时，出处之下也能多空一行）、`open_air=3`、`fig_scale={'图': 比例}` 缩放一幅图、`fig_air={'图': 3}`（这幅图上下可多留到 3 行空）。用 `tools.modplan` 看分页计划，找出差几行、卡在哪个标题组上。
- **报告前一定先重新生成**：代码改了而 PDF 是旧的，报告会出错或数字不对。

### 4.6 标题

| 现象 | 办法 |
|---|---|
| 序号和标题之间的空格被吞掉或不统一 | `regap_heading`：序号后统一用全角空格（“第一章　…”“附录一　…”），西文序号后用一个空格（“§1. …”）；“一、”这种自带顿号的保持原样；序号后紧接“：”“、”“．”的（第 39 册推荐阅读“第1章：世界观”，黑格尔第 4 卷“第二期：独断主义和怀疑主义”）也不加空格（16 开书的 `bk.regap_heading` 和黑格尔、康德、杜威的 `normalize.regap_heading` 都是这样） |
| 误把“第一部　分”“第七章　的补充”拆开 | 序号模式加否定前瞻 `(?![的分])` |
| **长章题在词组中间断开**（“第十七章　将汉帝国 / 理论化的哲学家：董仲舒”） | 一行排不下、章名一行排得下时，章号单独一行，章名完整排在下面（`normalize.ORD_ALONE`）；章名本身也排不下时，章号仍单独一行，章名在下面平衡断开（第 19 册附录 D、E）。其他长标题按标点、虚词平衡断行，不断日期、书名号内部；介词“对、从、向”可以起行 |
| 标题里的强制换行、多余空格 | `head_clean` 去掉 |
| 标题里的注释角标落到行首 | 强制换行放到角标之后 |
| 标题、副标题用“／”或“——”分隔 | `head_split` / `merge_dash_head` |
| “Chapter 1”和中文章名之间是换行（U+2028） | `head_sub` 换成“／”，`head_split='／'` 分两行，`head_split_balance=True` 让长章名自己再平衡断行，`head_split_join='\u3000'` 让目录、书签、页眉里仍是一行 |
| 章首页差一行排不满（章题和几段正文之后紧跟一个放不下的小节标题） | `open_air=True`：章题下的正文可以下移一行（代价 60，低于页底留白）。代价可按书改：`open_air_cost=(一行, 两行)`（第 39 册 `(30.0, 45.0)`，默认代价下有两处孤行） |
| 章首页差两三行排不满，求解器把空行塞在引文和出处之间（第 25 册第四章，引文下空了两行才是“——卡尔维诺”） | `open_air=2`：出处紧跟引文，空行放在“引文＋出处”这一组的下面（最多两行，代价 10/25） |
| 章首页几段文字怎么调字距行数都不变，差一行排不满（第 26 册第 13 章） | `open_air=3`：章名下第一段最多下移三行（代价 60/150/300，只在别无办法时用），在说明里写明哪一章 |
| 小节标题是整段加粗的普通段落（第 26 册） | `bold_head=(3, 40)`：不超过 40 字、不以句号等结尾、整段加粗的段落算三级标题 |
| 章号和章名、部分号和部分名、“推荐序一”和题目是两个标题（第 26 册） | `head_join`：合成一个标题，章号后用全角空格，推荐序用“／”分两行（目录里仍是一行） |
| 电子书把个别小节标题标成和章名同级（第 26 册“证真偏差”“事实与价值观”） | `head_relevel={'证真偏差': 3}` |
| 章首题词在电子书里是普通段落，只有出处“——某某”有自己的类（第 29 册） | `epi_quote=True`：章名下、“——出处”之前的普通段落按题词排（楷体、左右缩进），出处紧跟其下右对齐 |
| 部分页上的题词、导语不在正文行格上（部分页的标题位置固定，题词跟在后面） | `part_grid=True`（第 28 册）：题词每行单独定位，基线落在行格上；导语是长段落时用 `part_epi_para`（第 24、27 册） |
| 部分页之后紧跟一个“精彩内容：”小标题和几行要目（第 59 册） | `part_list=r'^精彩内容'`：标题和要目排在部分页上（要目左对齐、整体居中、落在行格上），不另占一页 |
| 部分（篇）名之后、第一章之前有几段没有标题的导言（第 38、40 册） | `part_intro=True`：导言排在部分页之后，不作书签和目录条目（`mod.nobm`），页眉用部分名 |
| 节号“I”“II”和“视觉”“脂肪”这类小节名是居中的普通段落（第 33 册） | `cls_sep=('center',)`：居中，上下各空一行，不落页底 |
| 同一个段落类有的是小标题、有的是标签（第 34 册 `content-b`：“系统之思 / THINKING IN SYSTEMS”是要点段后的标签） | `head_cls={'content-b': (5, r'^(?!系统之思$|THINKING IN SYSTEMS$)')}`：只有匹配的排成标题；标签用 `text_map` 右对齐 |

### 4.7 插图与表格

| 现象 | 办法 |
|---|---|
| 插图放哪里 | 现行（第 16 册起，`fig_inline`）：图留在正文原位，图题在图下；本页放不下时浮到下一页页首，后面的正文先把本页排满；必要时图上下多留一两行，避免缺行或孤行。**会让页底留白的图自动移到书末**（`bk_build.blank_foot_figures`，章末页除外），一页一图，页首“插图N”加图注，页底“↩ 返回正文（第N页）”；正文原处是图题加蓝字黄框的“见书后插图N”，双向可点。第 1–10 册和黑格尔、康德、杜威是旧规则：正文中间的图一律后置 |
| 整页图（封面、书名页、作为整个章节页的图、二维码、封底、签名） | 留在原位，不后置（`inplace`、`front` 的 figure 类型、`tail`） |
| 书末二维码页是一整张宽图，按默认 130 pt 宽排得太小（第 27 册） | `tail_w=320.0`：书末 `tail` 图的宽度（pt） |
| 书末是几十页原书扫描图（参考文献），有的是修补者重做的 SVG，标题上挂着一条说明注（第 29 册） | `back` 里 `(n, 'figpages')`：一页一图，SVG 也可以；标题上的注不排角标，注文排在标题下 |
| 插图太大或太小 | 按原书扫描分辨率定印刷尺寸（`fig_dpi=300`），图里的标签约与正文同大；SVG 用它的单位当像素（`special.img_size` 支持 SVG） |

### 4.8 注释

- 角标格式（`marker`）：
  - sq：[n]；校订注排成 [校n]。
  - paren：(n)。
  - keep：照电子书，[n] 是作者注，(n) 是译者注。
  - sqcirc：作者注 [n]；电子书里带方括号或写成 0n 的译者注排成 ①②③。
  - plain：电子书里的裸数字，加方括号排成 [n]。
  - zhu：註n（繁体书）。
- 角标与注释双向链接；角标不落行首（前面加词连接符，打印时去掉，见 4.4）。电子书里本来就是上标的注码、标题里的注码同样要加（复查时黑格尔第 1、3 卷的 39 个注码、康德第 7 册一个标题注码落在行首，就是漏了这一步；标题里的要在断行平衡之后加，否则平衡结果会变）。
- 注释的位置：
  - 默认排在章后；相邻短章的注释合成一组，每章前加小标题（`NOTE_MIN` 约两页小字），不出现只有几行的注释页；
  - 全书注释很少时（第 30 册 10 条），`notes_end=True`：全部排在正文之后一处，每章一组；
  - 带文字标签的角标（第 59 册：译者注 [n]、修补者补的原作者脚注 [原注n] 和书末资料注 [资料n]）：`mark_label='原注|资料'`，照电子书印出的样子排成上标，整个不拆开（标签每个字之间加词连接符），注释条目同样认得，`qa_marks` 也按它核对；章末的“原作者注释”标签用 `head_drop` 不排；书末注释节的网址用 `url_break_back` 允许断行；注释条目的锚点在段落上（而不在链接上）的，注释段落带上段落的 id；
  - 角标在电子书里是一张图片（第 59 册编者注 [3] 是整张表格图片的链接）：`img_mark={'图': ('[3]', '注释的 href')}`，图留在原位，角标补在前一段末尾，注释回链到角标（单独一行的角标是孤立角标行，不行）；
  - `notes_end='all'`（第 36–40 册）：前言等书前部分、正文、书末部分（附录、总结）的注释全部排在全书最后一处，每部分一组（第 37 册的注释原来按篇幅分在第 7 章后和结语后两处，第 40 册前言的一条注释原来单独占一页）；
  - 两套注释（第 31 册：作者注是书末的裸数字注，编者注、译者注是每章末尾的 [n]）：`circ_link` 让后一套排成 ①②③，`notes_title`/`notes_toc` 给它的那一节命名，两套各自成节；
  - 第 33 册：每章末尾的脚注（作者注、译者注）排成 ①②③ 放在章后；书末“注释及出处”的出处注保持 [n]，在原位按章分组（`XNOTELINK` 互链）；
  - 第 34 册：电子书把全部注释放在书末一个文件里，原书注释（图标角标）和本次校订注各成一组，合成书末一节“注释”；
  - 整本书的尾注排在书末；
  - 自序等前置部分的注释排在该部分之后。
- 注释号放在 3 字宽的行内块里（`.nn`，要设 `text-align-last:left`，否则“[校4]”会被拉开）。
- 多看格式的 EPUB3 脚注（第 26 册）：角标是 `<a epub:type="noteref">` 里的小图标（`image_000.png` 等，替代文字就是注文），注文在前面的 `<aside class="duokan-footnote">` 里。抽取时图标换成编号角标（`renum=True` 按章编号），`<aside>` 的注文作为注释排在章后；图标前电子书的换行不留空格。预检把这些图标单列为“注释角标图标”，不算要转写的小图。同一本书里另有一套“[1]”式章末注（“[”“1”“]”各自是一个链接）：先合成一个角标，再与脚注统一编号。
- 链接把后面的正文也包进了上标（第 29 册“[4]。哪怕”）：抽取时拆开，注码照常上标，后面的字回到正文。
- 注码在电子书里是纯文字、链接挂在别处（第 28 册编者注“[1]”挂在“事件”后的空位上）：`ADDMARK` 在原位置补可点击的角标，删掉纯文字的“[1]”。
- 检查：`python -m tools.qa_marks NN`，问题数为 0。
- 注释里有表格（第 2 册注释 [11] 是一张表）：表格随注释排，小字、表头加粗（`note_table_blocks`）；抽取时 `<aside>` 等注释容器里的 `<table>` 标 `innote`。
- **没有链接的注码**（第 53 册译者注“（n）”是普通上标，第 57 册“[n]”是普通上标，第 58 册“（n）”是普通文字）：`PNOTES` 按章末“注释：”标签把注释分块，正文的注码与下一块里同号的注释配对、双向链接。要点：
  - 一块注释到下一个标题（或作者原注）为止；所以电子书排成正文的标题要先用 `HEADRE` 改成标题，否则后面的正文都被当成注释续段（第 57 册第一次构建，68 页“注释”）；
  - 作者原注 [n]（`<p id="annotN">`，`note_cls` 加 `noindent`）照电子书的链接；链接到同一部件里的上标 [n] 是作者原注的注码，不当译者注码（第 53 册的 [98] 链接到 `#aid-…`，以前被认成译者注 (98)）；正文段落以作者原注注码开头的不是原注（`anote` 要求回链指向 `#ref…` 或段落 id 含 annot）；
  - `<span class="super" id="refN"><a href=…>[1]</a></span>`：span 的 id 是注码的锚点；`<a href=…><sup id=…>57</sup></a>`：sup 的 id 是锚点（第 56 册注 57–60 以前没有回链）；
  - 普通文字的注码（`plain`）按编号顺序认（只认比上一个大 1–3 的，避免把年份、列表号当注码；前后颠倒一两个的也认）；作者原注里的注码不受顺序限制；
  - 电子书缺注文的注码不加链接（第 57 册 [6]），正文里找不到注码的注释不设回链（第 53 册 7 条）；`qa_marks` 另列出来，不算问题。
- 注释只有一张图（第 49 册注 10，拿破仑墓）：`note_plates` 把图移到书末，“（见书后插图1）”接在注码后面，不另起一行。
- 同一条注释被正文引用两次（第 55 册注[75]，电子书注里有两个返回箭头）：角标比注释多一个，照排；残留的返回箭头“↩2”删去。

### 4.9 目录、书签、页码、索引

- 目录列章、节两级（`toc_sections`；节太多或没有节时只列章，如第 16、23 册）。点线引导，页码可点。
- **目录疏密一致**（第 23 册用户指出）：设 `toc_even=True`，空行固定为每章（只列章时每部分）前一行、前置部分/正文/书末之间一行；不设时空行会为凑满页面在 0–2 行之间变动，显得疏密不一。
- 索引页码由原书印刷页换算成本 PDF 页码并加链接（黑格尔；方法见 `docs/index-pages.md`）。
  - 正文里留有原书页末标记时（第 23 册），用 `back` 里的 `(部件, 'index')` 加 `index_map=锚点正则`：原书第 N 页 = 第 N−1 页标记到第 N 页标记之间，在其中（或前后约 500 字内）找条目的中文词，找不到取该页开头；精确，不用推算。逐条结果写在 `out/bNN.index-map.csv`。
  - 索引第一行“见本书边码”之类的说明要随之改写（写成一条 `FIXES`）。
  - 页码范围“148—149”的连接号后有词连接符，`indexmap.NUM_RE` 已能认出。
- 电子书里没有纸书页码标记的索引（第 48–51 册），页码照原样是纸书页码，在说明里写明；要换成本 PDF 页码只能按条目词推算，等用户决定。
- 目录末页只剩一两条（第 49 册）：`toc_even` 的空行是固定的，可设 `toc_part_tight`（篇名下第一章不空行）。
- 原书印刷页码标记排成小号〔n〕放在段末（`pgno_cls`）。
- 封面后紧接的勒口、品牌页（`front_flaps`）不再各自生成一个“封面”书签，只留一个（第 30 册）。

### 4.10 校订（只在要求时做）

- 导出全书：`python -m tools.proof_dump NN`，导出到 `$Q/text/c001.txt`…，一段一行。逐片通读，**不能跳片**（以前跳读漏过几片，后来回头补读）。
- 机械扫描：`python -m tools.proof_scan`，查重字、常见错字、标点、空格、繁简混用、句中断段，作为通读的补充，不能代替通读。
- 每条改正写成 `FIXES` 里的一条规则，附分类说明（错字、漏字、多字、标点、用字、排版、错译、事实、人名、书目、外文）。`bk_report` 的 fix_unused 必须为空（规则失效会被报出）。
  - 字面量里的空格、破折号要与原文的实际字符一致（U+2005、U+2009、—— 等），先跑规范化规则，再写后面的字面量。
- 作者有意为之的不改：文字游戏、藏头、故意的重复和倒装、作者自己的用字（第 17 册的《美国人性格》）。证据不足的保持原样并列出。
- 有英文原著时，对照原著核错译、事实、人名、书目。
- 生成勘误表：`python -m tools.bk_errata NN`。

### 4.11 环境与工具的坑

- **不要用 `pkill -f "tools.…"`**，会杀掉自己的 shell。按 PID 精确匹配。
- 长时间构建放到后台运行，用 Monitor 等待结束，不用 `sleep`。
- 网络：`raw.githubusercontent.com` 和 npm、PyPI 可以访问；unicode.org、github.com 网页、Google Fonts 网站被拦。需要全字库字体时，npm 上有 `fontpkg-jigmo`（字云，CC0）。
- jieba、zhconv 用 pip 装不上；opencc 可用。
- `grep -o` 在字节 locale 下会切坏 UTF-8：用 Python，或者 `LC_ALL=C.UTF-8`。
- 用 Python 改源码时用带断言的整段替换（`assert s.count(old)==1`）；断言失败就不写入，检查后重做。
- 正则里的汉字范围写成 `\u4e00-\u9fff` 这样的转义，不要直接写字（直接写的字在编辑、粘贴时容易变样，也看不清范围）。
- 电子书是不受信任的输入：解析时不解析实体、不联网（`preflight`、`special.img_size` 都这样做）。
- 渲染 SVG 用 Chromium（Playwright），系统里没有 rsvg 和 cairosvg。

### 5.2 其余检查

## 附录 B　`bk_fixes.FIXES['qNN']` 规则格式

| 形式 | 作用 |
|---|---|
| `(部件, '旧文字', '新文字', '说明')` | 字面替换，可跨同一段里的不同格式的文字 |
| `(部件, re.compile(r'…'), r'替换', '说明')` | 正则替换；部件写 `'*'` 表示全书 |
| `(部件, 'HEAD', '段首文字', 级别, '说明')` | 把排成正文的段改成标题 |
| `(部件, 'PARA', '段首文字', '另起段的文字'[, '说话人'], '说明')` | 从某处另起一段（可标说话人） |
| `(部件, 'JOIN', '前段末尾', '后段开头', '说明')` | 两段合并 |
| `(部件, 'MOVE', '要移的段的开头', '移到这段之前', '说明')` | 移动一段（或一个标题） |
| `(部件, 'CELL', '行首格', 列, '旧', '新', '说明')` | 改一个表格单元格 |
| `(部件, 'SPLIT', 段首, 拆分文字, 标签, 回链, 锚点, '说明')` | 把并进前一条的注释拆出来 |
| `(部件, 'RENUM', 增量, …)` / `(部件, 'SHIFT', 起始号, 增量)` | 注释重新编号 |
| `(部件, 'RELINK', 段首, 角标, 新角标, href, 锚点, '说明')` / `(部件, 'ADDMARK', 段首, 前文, 新角标, href, 锚点, '说明')` / `NOTEBACK` | 改正链接错位的角标、补漏掉的角标、修注释回链 |
| `(部件, 'HREF', 段首, 链接文字, 新 href)` / `(部件, 'ANCHOR', 段首, 锚点)` | 改链接目标、补锚点 |
| `(部件, 'PGNO', 文字+页码)` | 把混进正文的原书页码分出来 |
| `(部件, 'NOTELINK', 注释段的类, '说明')` | 这一部分里纯文字的“[n]”角标与“[n]…”注释排成上标并互链 |
| `(部件, 'MOVETAB', 表题, 下一段开头, '说明')` | 表格连同表题移到那一段之后（浮动到下页页首，免得页底留白） |
| `(部件们, 'XNOTELINK', 注释部件, 分组正则, '说明')` | 各章不带链接的上标 [n] 与书末注释部件里同一章的第 n 条互链（第 k 组对第 k 个章部件） |
| `(部件, 'PARATABLE', 首段开头, 行数, '说明')` | 用空格对齐的几行文字排成表格 |
| `('*', 'FWPAREN', 前一字的正则, '说明')` | 中文里的半角括号改全角（前一字匹配，或括号里有汉字），逐字替换，不动文字分段 |
| `(部件, 'HEADRE', 正则, 级别, '说明')` | （第 57 册）符合正则的段落都排为标题；罗马数字序号后补全角空格（在 `PNOTES` 之前生效：标题结束一块注释） |
| `(部件, 'PNOTES', 选项, '说明')` | （第 53、57、58 册）没有链接的注码与“注释：”标签下的注释按块配对、双向链接；选项 `to`（注码是另一部件的）、`ext`（注释回链到另一部件）、`plain`（注码是普通文字“（n）”，按编号顺序认，作者原注里的不受顺序限制）。找不到注文的注码不加链接，找不到注码的注释不设回链 |
| 正则里的 `\0` | 代表一个行内小图（规则中间夹着公式图时用） |
| 注意 | 匹配范围跨过角标、斜体等不同格式的文字时，替换结果只保留第一段的格式：角标会变成普通文字。只匹配要改的字（零宽前后断言），或用 `FWPAREN` 这类逐字的规则；零宽的匹配本身不会被应用 |
