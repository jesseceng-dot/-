# 《初中数学竞赛多功能题典（最终校勘版）》校勘说明

## 一、概况

### 1. 底本与成果

- **底本**：`初中数学竞赛多功能题典_最终校勘版.pdf`，A4，483 页（书上所印页码 = PDF 页码 − 5），XeLaTeX 排版，共三十章，收练习题 1725 道。
- **成果**：`初中数学竞赛多功能题典_校勘修订版.pdf`，483 页，页序、页码、书签、版式与底本相同。
- **旧补丁**：底本此前经过一轮修补，做法是在 PDF 上用白框遮住原字，再叠印新字（本说明称“旧补丁”）。旧补丁本身带来了不少新问题：“∠”缺横线、字距缺失、新旧字形重叠、行超出版心、白框下残留原字，个别题目的公式被整行涂掉。这些问题本次一并处理。

### 2. 校勘范围

按要求检查缺、漏、多字，上下角标，特殊字符错误，错题。影响阅读或不合出版要求的排版问题也一并处理，包括句中误分段、行超出版心、压字、标点误用等。

### 3. 原则

1. **有充分理由才改。** 错题、错字都经过推导或数值验证（代入、穷举、坐标计算），依据写在明细表的“问题”栏。只是体例不统一、不影响理解的，记录不改（见第三、五节）。
2. **不改变原排版风格。** 只重排有问题的段落。重排沿用原书的排版参数：XeLaTeX/ctex，正文 10.9pt，原书的行距与版心，两端对齐，中西文间距，行内分式用 displaystyle，数学式内用半角标点。字形全部取自书中已嵌入的字体，也沿用原书体例（如句号用“.”，数学式后的逗号排在数学式内）。没有改动的行保持原样。
3. **符合出版物排版要求。** 不出版心、不压字，不残留补丁白框。段落行数变化时，下方内容整体移动，不与图表冲突。字体全部嵌入，文字可以检索。
4. **推定复原单列。** 原文已经丢失、只能根据题意推定的内容，集中列在第四节，注明依据和把握程度，建议对照原书核对。

### 4. 方法

1. **逐页通读**：提取每页的文字与版面，逐题核对题意；可疑的题目做推导或数值验证。
2. **程序扫描全书，逐条人工复核**：扫描项目包括“∠”缺横线、绝对值竖线间距、句点紧接字母、顿号前多余空格、行超出版心、无 Unicode 映射或未嵌入的字形、撇号字号、度号未上标、正文字体混入数学式、单位正斜体、全角/半角标点、“如图”与插图是否对应等。
3. **修改**：用与原书相同的参数模拟排版。先把未改的原文排一遍，确认与原书逐字形重合（偏差在 0.1pt 以内），再施加修改，只替换发生变化的行。插图按原图的线宽、字体和尺寸重绘或调整。
4. **核验**：每处修改都做了改前、改后对照；全书逐页比对，修改范围以外的页面与底本完全相同；PDF 语法检查无错误，483 页全部正常显示，字体全部嵌入。
